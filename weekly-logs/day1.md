# Day 1: The Start

## 1. Why did I start this project?
I'm a beginner programmer, and I wanted to learn C++ for game development. This is something I have wanted to do since I was a kid. Throughout the last year, I have gained a basic understanding of how programming languages work. However, I have never been able to finish a program because I lacked the core skill. To bridge that gap, I bought the book *Beginning C++23*.

## 2. Why a Virtual Machine?
While reading through the first chapter of the book, I reached page 16. In the section "Representing Numbers" under the subsection "Binary Numbers," the text briefly explains how a binary system works. I found this fascinating. Shortly after, I did some research because I had never understood how simple 0s and 1s could come together to create a computer.

After getting a quick view of binary systems, I became deeply interested in building a computer from scratch. First, I looked online to see if I could build one inside Minecraft. I found the idea of making a virtual game inside another game fascinating. I watched a few tutorials, but since the only way I could play Minecraft was on a Switch 2, I found it very difficult to proceed without proper mod tools.

Because of that, I decided to test my ideas using a small C++ program with the knowledge I had gathered before reading the book. With a bit of help from a YouTube tutorial (*"How to Make a Redstone Computer from Scratch"*), I successfully built an ALU.

An ALU (Arithmetic Logic Unit) is one of the most vital components of any processor. I managed to make it work in C++ using string-based binary numbers, loops, and custom classes. At first, my plan was to build an 8-bit computer. But I quickly realized that even without reading the book—which defeated the entire purpose of my learning plan—I could complete that project without learning C++23 at all.

After some careful thought, I decided to scale up. I am now building a 32-bit system with the performance equivalent of a PlayStation 1, capable of running simple 3D games.
